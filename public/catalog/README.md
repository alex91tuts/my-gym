# Catalog exerciții

Sursa: [free-exercise-db](https://github.com/yuhonas/free-exercise-db), domeniu public (The Unlicense).

- `exercises.json`: versiunea compactă a `dist/exercises.json` (id, nume, echipament, categorie, nivel, mușchi, instrucțiuni, nr. poze). Numele și instrucțiunile sunt traduse în română; numele original e în `en`.
- `img/`: pozele de start și final, combinate, pentru exercițiile de start din `src/lib/seed.ts` (descrierile în română sunt în `src/lib/seedMedia.ts`).

Schema corpului vine din [react-body-highlighter](https://github.com/giavinh79/react-body-highlighter) (MIT).
